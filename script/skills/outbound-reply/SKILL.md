# 怎么回消息

通道怎么把一句话发出去。调哪个工具看 MCP 技能；人设看人设模式。
不要把协议行念给用户听。不要编链接。标题/描述里不要写 `|`。

配文一句，媒体或卡片另起一行。不要把随便一条 http 都当成卡片。

## 什么情况发什么

先看手里有什么，再选一种，不要叠发（别又发图又发卡片）。

- 闲聊、问答、工具只给了人话：纯文本
- 反应、梗、表情包：有 md5 发**表情**；没有 md5 当**图**
- 画图、分类图、今日老婆、工具给了图片链接：发**图**
- 工具给了视频链接：发**视频**
- 歌、且有可播的音频直链：发**音乐卡片**
- 网页、文章、分享页、规则 `kind=link`，或歌但只有播放页没有音频：发**链接卡片**
- 只是让人点开看看、不必做成卡片：普通链接裸写一行
- 规则给了整段 xml：按卡片里的 `app:` 发

图链不要改成卡片；视频不要当图发；没有音频直链不要硬发音乐卡片。

## 图 / 视频

一句配文 + 下一行裸 `http(s)` 链接。不要 `![]()`、不要 `[文字](链接)`。

## 表情

有 md5：单独一行 `emoji:<32位hex>` 就够，Golem 只靠 md5 就能发出去，不必再跟 `imageUrl`。
没有 md5：当普通图发。不要编 md5。

## 卡片

- 链接卡片：`link:标题|描述|url|封面`（封面可空：`link:标题|描述|url`）
- 音乐卡片：`music:歌名|歌手|页面url|音频url|封面`
  - 没有可播的音频直链就改用 `link:`，不要编 dataurl
- 规则给了整段 xml：`app:类型 <xml...>` 仍须一行
- 规则 `kind=link`：用 meta 的标题/描述/封面 + value 拼 `link:`
- 规则 `kind=app`：能当音乐就 `music:`，只有网页就 `link:`

## 普通链接

不当卡片时，链接单独一行裸写，不要括号包住。
