# 怎么回消息

通道怎么把一句话发出去。调哪个工具看 MCP 技能；人设看人设模式。
不要把协议行念给用户听。不要编链接。标题/描述里不要写 `|`。

配文一句，媒体或卡片另起一行。成功发出媒体后，不要再用同一条 URL 补一张卡。

## URL 怎么发

只谈 `http(s)` 链接。表情 md5、应用 xml、转发记录不走这条。

1. **这条 URL 带了类型**（`link:` / `music:` / `app:`，或规则 `kind=link|app`）→ 按标明的发
2. **能认出是视频**（常见 `.mp4` 等）→ 下一行裸链，当**视频**
3. **能认出是图片**（常见后缀、或 `/i/` 20 位短链）→ 下一行裸链，当**图**
4. **认不出，或上面发送失败** → **链接卡片**

未标明的音频、播放页、文档、无后缀短链，都走第 4 步。不要猜语音还是音乐。

规则 `kind` 算标明类型：`link` 拼 `link:`；`app` 能当音乐就 `music:`，否则 `app:`。`kind=voice` 若只有音频 URL、没有语音协议，按第 4 步发卡。

## 什么情况发什么

先看手里有什么，再选一种，不要叠发。

- 闲聊、问答、工具只给了人话：纯文本
- 反应、梗、表情包：有 md5 发**表情**；没有 md5 当**图**
- 画图、分类图、今日老婆、工具给了图片链接：发**图**
- 工具给了视频链接：发**视频**
- 歌、且有可播的音频直链：发**音乐卡片**
- 网页、文章、分享页、未标明的 URL：发**链接卡片**
- 规则给了整段 xml：`app:`；聊天记录 xml 见下面转发

图链不要改成卡片（除非发送失败）；视频不要当图发；没有音频直链不要硬发音乐卡片。

## 图 / 视频

一句配文 + 下一行裸 `http(s)` 链接。不要 `![]()`、不要 `[文字](链接)`。

## 表情

有 md5：单独一行 `emoji:<32位hex>` 就够，不必再跟图链。
没有 md5：当普通图发。不要编 md5。

## 卡片

- 链接卡片：`link:标题|描述|url|封面`（封面可空：`link:标题|描述|url`）
- 未标明的裸 URL 也可以只写一行 `http(s)`，通道会当成链接卡片
- 音乐卡片：`music:歌名|歌手|页面url|音频url|封面`
  - 没有可播的音频直链就改用 `link:`，不要编 dataurl
- 规则给了整段 xml：`app:类型 <xml...>` 仍须一行

## 转发卡片

微信里的「聊天记录 / 合并转发」**不是一条 URL**，不要把网页、视频、音频包装成转发卡。

- 工具给了整段记录 xml：`app:19 <xml...>` 一行发出去
- Golem 另有「转发已有 CDN 图/视频/文件」，也要原消息 xml，模型不要自己拼
- 发送失败：xml 里若有可点的网页地址，才降成 `link:`；没有就说没发出去，不要假装发成了链接卡
