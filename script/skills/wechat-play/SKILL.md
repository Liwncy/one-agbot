# 微信专属玩法

只写绑在这台微信登录态上的工具。画图、天气、聊天记录、庄园仍走「MCP 工具用法」。发出去的格式走「怎么回消息」。

## 随机朋友

对方说蕉个朋友、捞个好友、交个朋友、来个朋友、随机朋友、随机名片 → `golem_random_friend`

- 不用填参数。不要自己编手机号、wxid 或名片
- 成功 `status=ok`：配文用 `caption` 或改成一句口语；下一行把从 `app:` 开头的那一整行原样贴出去。不要改 xml，不要拆成多行，不要把 xml 念给用户。发出去前读「怎么回消息」
- 没找着 `status=empty`：用人话说这次没捞到，不要编一个人
- 出错 `status=error`：说没弄成，不要念字段名或错误码

## 聊天记录卡

对方说编聊天记录、做聊天记录卡、假聊天记录、伪造聊天记录、编一段群聊记录 → `golem_fake_forward`

- 本条有「被@」：这些人就是角色，按序号入戏。`script` 用他们的名字；`avatars` 把该行 `avatar=` 后的 URL 原样写上（`姓名=https://...`）。不要自己编头像，不要再问「叫什么」
- 有被@但没台词：只问对白，不要自己编，也不要先调工具
- 没被@时，对方用口语说角色和台词，你整理后一次调用，不要拆成多轮草稿口令
- 没被@也没说角色或台词：先问缺什么，不要自己编对白，也不要先调工具
- 图片/视频先写成文本占位，如 `[图片] 海边日落.jpg`，不要当真图发
- `script` 每行一条：`姓名|时间|内容`。时间用 `09:12` 或 `2026-04-29 09:15`；没有时间用 `姓名|内容` 或 `姓名||内容`
- `title` 可选，默认「群聊的聊天记录」
- `avatars` 可选，每行 `姓名=https://头像`；没有头像就不填
- 成功 `status=ok`：配文一句；下一行把从 `app:` 开头的那一整行原样贴出去。不要改 xml，不要拆行，不要念给用户。发出去前读「怎么回消息」
- `status=ask`：按 hint 只追问缺的
- `status=error`：说没弄成
